# 🎮 Video Game Sales Dashboard

An interactive Excel dashboard project focused on analyzing global video game sales trends across genres, platforms, regions, and release years.

## ✨ Features

### KPI Cards
| Metric | Description |
|--------|-------------|
| 🌍 Total Global Sales | Sum of all video game sales worldwide |
| 🎮 Total Games | Total number of games in the dataset |
| 📈 Average Global Sales | Mean sales per game globally |
| 🏆 Top Genre | Best-performing genre by total sales |
| 🖥️ Top Platform | Best-performing platform by total sales |

### Sales Analysis
- **By Genre** — Compare performance across action, sports, RPG, and more
- **By Platform** — Breakdown across consoles and PC platforms
- **By Region** — North America, Europe, Japan, and other markets
- **By Year** — Track sales trends over time

## 📁 Dataset

The project uses a video game sales dataset containing:
- Global and regional sales figures
- Game titles, genres, and release years
- Platform and publisher information

---

## 🎯 Objective

To build a clean, interactive Excel dashboard that delivers actionable insights into video game sales performance and global market trends — without requiring any coding or external tools.

- Data Visualization & Dashboard Design
- KPI Development & Business Insights

---

## 🚀 How to Use

1. Download or clone this repository
2. Open the `.xlsx` file in Microsoft Excel (2016 or later recommended)
3. Use the **slicers** to filter by genre, platform, region, or year
4. Explore the **KPI cards** and **charts** for instant insights
